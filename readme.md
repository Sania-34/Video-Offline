# Video Offline

Офлайн-додаток для Windows на базі **pywebview + локальний HTTP-сервер + WebView2 (Edge)** + **yt-dlp + ffmpeg**. Дозволяє скачати відео з YouTube та переглядати його без інтернету, зберігаючи у папці поруч із програмою.

---

## 📌 Що робить програма

«Video Offline» — це простий офлайн-клієнт для завантаження відео з YouTube на комп'ютер. Після завантаження відео зберігається у папці `cartoons/` поруч із `.exe`, а програма дозволяє переглядати їх без підключення до мережі.

---

## ⚡ Основні можливості

- **Завантаження відео з YouTube** — вставте посилання, натисніть «Скачати», програма покаже прогрес і повідомить, коли готово.
- **Автоматичне видалення .mp4** — після конвертації ffmpeg залишається лише оригінальний `.webm` файл (збереження місця на диску).
- **Розділи (категорії)** — створюйте свої розділи (наприклад, «Мультики», «Відео», «Обучаючі» тощо), перейменовуйте та видаляйте їх.
- **Переміщення відео між розділами** — кнопка «➡» на картці відео.
- **Видалення відео з диска** — кнопка «✕» видаляє файл з папки і з обох плейлистів.
- **Вибір колору акценту** — 7 кольорів у Налаштуваннях (фіолетовий, червоний, зелений, жовтий, світло-розовий, сирий, голубий).
- **Єдине вікно** — програма не дозволяє запустити другий екземпляр одночасно.
- **Іконка програми** та окрема назва «Video Offline».
